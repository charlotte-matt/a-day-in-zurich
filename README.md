# A Day in Zürich 🇨🇭

An interactive walking map for a one-day itinerary in Zürich — clickable stops
with times, photos, addresses and one-tap directions, plus arrows tracing the
route through the day (arrive → Bahnhofstrasse → the lake → Old Town → dinner).

**▶ Live map:** https://charlotte-matt.github.io/a-day-in-zurich/

Everything is in a single self-contained `index.html` (the photos are embedded).
Just open it in any browser — an internet connection is needed for the map tiles.
